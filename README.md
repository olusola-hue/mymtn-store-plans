# myMTN NG — Store Plans Prototype

A standalone static HTML/CSS/JavaScript prototype for the myMTN Nigeria Store Plans page.

## Deploy on Vercel
1. Upload `index.html` and `README.md` to the root of the `mymtn-store-plans` GitHub repository.
2. In Vercel, choose **Add New → Project**, import `olusola-hue/mymtn-store-plans`.
3. Framework Preset: **Other**. Build command: leave blank. Output directory: `.` (or leave default if Vercel detects static files).
4. Click **Deploy**.

All prices, reward points and countdowns are illustrative, not live MTN offers.
