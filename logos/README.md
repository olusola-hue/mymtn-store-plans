# Logo files for the Entertainment tab

These are the logos shown on the Entertainment cards, with backgrounds removed
(transparent PNG, square canvas):

- `netflix.png`
- `apple-music.png`
- `spotify.png`
- `dstv.png`

Notes:
- The Spotify image came from a stock-image site and still carries a faint
  watermark. Replace it with the official asset from Spotify's brand-assets
  page before this goes anywhere public.
- Use official logos and follow each brand's usage guidelines.
- To swap a logo, overwrite the file here (keep the name) or change the
  `logo:` path for that entry in the `plans` array in `index.html`. If a file
  is missing, the card falls back to a neutral tile with the first letter.
