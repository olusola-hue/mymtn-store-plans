# Logo files for the Entertainment tab

Add the official logo for each service here, using these exact file names
(SVG preferred, square or near-square works best):

- `netflix.svg`
- `apple-music.svg`
- `spotify.svg`
- `dstv.svg`

Get them from each brand's official press / brand-assets page and follow its
usage guidelines. Until a file is added, the card shows a neutral tile with
the service's first letter.

To use a different file name or type (e.g. `.png`), change the `logo:` path
for that entry in the `plans` array in `index.html`.
